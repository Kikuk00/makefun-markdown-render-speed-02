Fast from-scratch Markdown renderer matching marked 18.1.3 — dependency-free, deterministic, 720/720 practice cases byte-identical.

`parse.js` is a from-scratch Markdown parser (no dependencies); `main.ts` is the driver that reads cases from `/input/cases.json` and writes rendered HTML to `/output/html.json`.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
